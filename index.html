Process

My recipe

What goes into everything I make. Not a checklist — just the standards I keep coming back to.

Start a project
  1. 01

    Clean code

    Readable, organized and easy to extend, so the next feature never feels like a fight.

  2. 02

    Fast by default

    Light pages, lazy images and no unnecessary libraries. Speed is a feature, not an afterthought.

  3. 03

    Pixel care

    Spacing, type and color are not decoration — they are how a page earns trust.

  4. 04

    Every screen

    Phone first, then tablet, laptop and wide monitor. Nothing gets cut off, ever.

  5. 05

    Real users first

    I build for the person using it, not just for the screenshot.
